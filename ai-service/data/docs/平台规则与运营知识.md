# 商户与优惠券使用规则

## 优惠券类型

平台目前有两类优惠券：

1. **普通券**：直接领取，领取后有效期内可用，不受限量约束。
2. **秒杀券（限量券）**：库存有限，先到先得，每人限购一单。

秒杀券的库存扣减在 Redis 中通过 Lua 脚本完成，保证「判断库存 + 扣减 + 记录下单用户」三步的原子性。

## 一人一单规则

同一用户对同一张秒杀券只能下一单。重复下单会返回「不能重复下单」。

这个限制由两层保证：
- Redis 的 Set 结构记录已下单用户，下单前先判断；
- 数据库层面 `tb_voucher_order` 上有 `(user_id, voucher_id)` 唯一索引兜底。

## 优惠券有效期

秒杀券有明确的活动时间窗口 `begin_time` 到 `end_time`，不在窗口内无法购买。
库存为 0 时，接口返回「库存不足」。

# 商户入驻与展示规则

## 商户评分

商户评分由用户评价聚合计算，满分 5 分。评分低于 3.5 分的商户不会出现在首页推荐位。

## 人均消费

人均消费（`avg_price`）是平台根据历史订单估算的参考值，单位为元。
排序和筛选时都以这个字段为准。

## 商户类型

平台把商户分为 10 类：1 美食、2 KTV、3 丽人/美发、4 健身、5 按摩、6 亲子、7 酒吧、8 轰趴、9 摄影、10 其他。

## 探店笔记

用户可以对商户发布探店笔记，笔记支持点赞、评论和关注作者的粉丝流推送。
点赞数基于 Redis 的 ZSet 统计，按点赞时间倒序展示排行榜。
