# 商户评分与排序规则

## 评分怎么算

商户评分满分 5 分，由该商户下所有有效用户评价聚合计算得出。评分保留一位小数。

平台不做人工干预，评分完全由用户评价驱动。新入驻且暂无评价的商户，评分按平台默认值展示，不参与推荐位排序。

## 推荐位门槛

评分低于 **3.5 分**的商户不会出现在首页推荐位，但仍可以通过搜索和分类列表访问。

平台目前评分分布区间大约在 3.7 分到 4.9 分之间。一个参考对比：同商圈里，评分 4.9 分的商户通常评价数也更多，说明高评分能带来更多曝光，形成正向循环。

## 排序字段

不同列表页的默认排序规则不同：

- **按类型浏览**：按商户 id 升序，同时结合评分
- **按名称搜索**：按名称模糊匹配，匹配度高的靠前
- **首页推荐位**：综合评分与累计售出数，评分低于 3.5 分的不进入

## 人均消费字段

人均消费字段 `avg_price` 单位是元，是平台根据历史订单金额估算的参考值，不是最低消费门槛，也不是套餐价格。

用户筛选「人均 50 以内」时，平台按 `avg_price <= 50` 过滤。注意这是估算值，实际消费可能高于或低于该数字。

## 累计售出与评价数

两个字段都是累计值，数字越大说明商户越受欢迎：

- `comments`：累计评价数
- `sold`：累计售出（订单）数

通过对比可以发现，售出数通常显著高于评价数，因为大部分用户下单后不会主动写评价。
